# Machine Learning Homework 3 — Complex Model

## Описание задачи
В работе решается задача бинарной классификации: предсказание наличия сердечно-сосудистого заболевания на основе медицинских показателей.

Используется датасет Cleveland Heart Disease.

---

## Модель
В качестве более сложной модели выбран ансамбль — Random Forest.

Причины выбора:
- устойчивость к шуму и выбросам  
- способность учитывать нелинейные зависимости  
- отсутствие строгих требований к масштабированию признаков  

---

## Подбор гиперпараметров
Оптимизация гиперпараметров проводилась с использованием GridSearchCV и кросс-валидации.

Подбирались параметры:
- `n_estimators` — количество деревьев  
- `max_depth` — глубина дерева  
- `min_samples_split` — минимальное число объектов для разбиения  

---

## Оценка качества
Модель оценивалась на отложенной выборке.

Используемые метрики:
- ROC-AUC  
- Recall  

---

## Интерпретация модели

### Глобальная интерпретация
Использован метод permutation importance для оценки важности признаков.

### Локальная интерпретация
Использован метод SHAP для объяснения предсказаний на отдельных объектах.
